## 便宜的那部分，缩水缩在哪

先花两句话讲清楚买的是什么。CN2 是中国电信的下一代承载网，号段 AS4809，分 GT 和 GIA 两种走法。GT 是半程优化，出了国门还得挤普通线路；GIA 去程回程都走电信自己的高端骨干。“三网回程 CN2 GIA”的意思是，电信、联通、移动三家访问这台洛杉矶机器，回来的路都强制落在 CN2 GIA 上。很多商家只保证电信回程走 GIA，联通移动随缘。

值钱的地方在晚高峰。普通 163 线路晚高峰延迟 300ms 以上、丢包可能超过 10%；CN2 GIA 晚高峰延迟稳在 150 到 160ms、丢包接近 0。这两个数字来自一份 DMIT 的建站整理，不是六六云的实测。六六云这台的晚高峰表现，我手上没有第三方实测数据，官网也没公开测试 IP，下单后那 48 小时退款窗口就是留给你自己测的。

缩水全在配置这一侧。200Mbps 端口，个人用够了，想跑大带宽中转、几个人同时拉 4K 就顶不住，而且这是共享带宽不是独享。820GB 月流量，写博客、跑轻量应用绰绰有余，做图床、放视频、给别人下大文件就不够。15G 硬盘装完系统和宝塔，剩下的空间不多，放两三个小站可以，存素材别想。1核1G 内存跑 WordPress，插件装多几个再上缓存就吃紧，2G 才算安全线。

那为什么还要买这种配置？因为现在有货本身就在涨价。DMIT 特价款天天断货，去交易区收动不动要给黄牛交大几十甚至上百块的溢价；VMISS 的便宜机器经常缺货，端口还只给 200M 到 500M。这是一份 NodeMach 促销讨论帖里的原话。想立刻开机、不想抢购，可选的范围就这么大。

## 常见问题

### ¥55/月这台的“三网 CN2 GIA”是真的吗？

官网商品名写的是“美国原生IP三网CN2 GIA大带宽”，第三方流量性价比排行也把它归在三网回程纯 CN2 GIA 那一类。但目前没有第三方路由实测公开，官网也没放测试 IP，我没法替你确认回程是否三家都落在 AS4809。想验证只能买回来自己跑 traceroute，所以先用月付试。

### 200Mbps 端口和 820GB 流量够不够用？

看用途。个人博客、轻量 API、几个人日常访问，够。跑 4K 中转、做图床、给别人下大文件，不够，而且端口是共享的，官方没有承诺独享。视频类和大流量站直接跳过这档。

### 和 DMIT Pro.TINY 差在哪？

内存差一倍，DMIT 是 1核2G，六六云是 1核1G；端口差五倍，DMIT 给 1Gbps，六六云给 200Mbps；价格差一半，DMIT 约 ¥67/月起，六六云折后 ¥44/月。DMIT 最麻烦的是缺货，六六云胜在现货和月付门槛。预算够、能等，选 DMIT；要今天就能开机，选六六云。

### 为什么比搬瓦工便宜那么多？

因为不是同一个东西。搬瓦工 CN2 GIA-E 是 3核2G、40G 硬盘、2TB 流量、2.5Gbps 端口，$299.99/年，约 ¥2001，配置高一个数量级。搬瓦工那些看起来便宜的套餐（MEGABOX-PRO、POWERBOX、BIGGERBOX-PRO）都是绝版二手，官网上买不到。

### 买了发现 IP 被墙怎么办？

服务条款第 5.2 条：支持自助换 IP 的产品，从首次开通成功记录起 1 小时内，可以针对被墙 IP 提交一次免费更换工单，由客服核验后处理，新 IP 随机分配。过了这个窗口，换 IP 按产品配置价格收费，滚动 72 小时最多成功换 1 次，每个流量重置周期最多 2 次，每个账户每自然月最多 5 次。第 5.3 条也写清楚了，除这一次性保证外，不对 IP 在中国大陆的持续可达性作承诺，被墙不算服务故障、不构成退款理由。这条得有心理准备。
